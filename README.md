# STARHEIRS

Party RPG blending classic elemental adventure, collectible/customizable machines/companions and relationship/evolution systems with a distinctive world and turn-based tactical combat.

## Unreal foundation
Narrative Pro 2 + Ultra Game Template 1.3. Recommended layers: Turn-Based RPG Template, Pocket Creature Tamer Adventure for collection/evolution reference, Element Reaction System, HKH Attribute System only if chosen as canonical stat implementation, Boss AI/content for exploration encounters, Narrative Pro for story/quests.

## Gates
V1: town/dungeon/world slice, party, turn-based combat, one machine/companion customization/evolution loop, elemental puzzle/boss. V2: full campaign, roster, deep customization, exploration/puzzles, progression. V3: expanded social/competitive/co-op possibilities where canon approves + AXIOM/PYRAMID edition.
