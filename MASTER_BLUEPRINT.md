# STARHEIRS Master Blueprint

## Systems
Party/formation; turn order/resource economy; elements/status/combo interactions; equipment; machine/companion acquisition; modular parts; evolution/upgrades; skills; relationships; towns/NPCs/quests; dungeon/world traversal; elemental field puzzles; bosses; crafting/economy; save/UI/accessibility.

Machines/companions must be data-driven: chassis/species, parts, stats, affinities, abilities, cosmetic identity, evolution/upgrade branches and ownership. Customization should alter tactical roles, not just numbers.

## Unreal
Narrative Pro owns story state. Ultra foundation. Turn-Based RPG Template is primary combat accelerator but canonical STARHEIRS combat rules supersede template defaults. Pocket Creature Tamer supplies collection patterns only where compatible. Element Reaction powers consistent combat/world element vocabulary. Avoid duplicate attribute/inventory/save systems.

## AXIOM
Implement same canonical battle simulator/data schemas and golden encounter tests in AXIOM. Content data should be portable through engine-neutral schemas.

## XYRA
Deterministic battle tests; turn-order invariants; save migration; progression/economy simulation; party soft-lock detection; puzzle recovery; controller/UI/accessibility; content validation; performance.

## Delivery
Data schemas → battle simulator → party/companion customization → exploration/narrative → elemental puzzles → vertical slice → content tools → campaign/roster → balance/polish → AXIOM track.
