# STARHEIRS — AXIOM Native Build

AXIOM implements the same engine-neutral party/battle/companion/puzzle/narrative schemas proven in Unreal.

Required AXIOM capabilities: party RPG state, deterministic turn/action engine, data assets, UI, dialogue/narrative adapter, animation/VFX, world/level streaming, save migrations and tooling.

STARHEIRS-specific: companion chassis/parts/evolution/fusion runtime, puzzle/traversal ability interfaces and golden battle replay suite. Unreal content becomes behavioral/reference data; engine-specific implementation is rebuilt behind shared contracts.
